SignalHub 是跨平台的桌面悬浮状态指示器。一组始终置顶、可拖拽的透明状态牌， 用颜色和明暗节奏表示当前状态。优先适配 AI 智能体，但不绑定智能体—— 任何程序只要能发一个 HTTP 请求就能上报。

At a glance

红比绿先看见，不看字也懂

十种状态压缩成四种颜色。全局取各组里最高的优先级；一块牌是一个组，最紧急的排在最前。 状态词在灯上用两字短词，把宽度让给名字。

绿 · 一切正常
idle 空闲 · thinking 推理（快闪）· working 执行（慢闪）· done 完成
黄 · 需要关注
attention 需要关注，闪
红 · 等你处理
permission 需要授权（平滑闪）· error 出错 / 阻塞（频闪）
灰 · 没在说话
stale 沉默 · offline 离线 · off 监控暂停

红 > 黄 > 绿 一组在等授权时，别的组报「正在执行」不会把红灯顶掉；等授权的那一组自己恢复工作后，红又自然消失。

  • 形状需要授权 / 出错的灯珠是圆角方形，其余是圆形。红绿是色盲最难分的一对，而这两档恰好最要紧。
  • 细环沉默的灯上是一枚细环，按剩余宽限期缩短，一眼看出它已经多久没说话了。
  • 明暗安静模式下空闲 / 沉默 / 离线的牌几乎透明，只有真有活动或需要你处理时才显形。
Daily use

每天都会用到的四件事

一行接上智能体
signalhub install hooks claude-code 装完重启即可。Claude Code / Codex / Cursor / Gemini CLI / Goose / WorkBuddy / opencode / Pi / Hermes 都有一键接入； 也可以完全不接智能体，用 signalhub working --session demo 或一个 HTTP POST 自己报状态。
等你批准时，灯会说话
「从灯上审批」把确认框搬到灯上的气泡里（默认关，目前只支持 Claude Code 的 HTTP 接入）。 危险命令要按住 800 毫秒才放行，命令看不全就只给拒绝；超时、开关关掉一律什么都不说， 永远不替你说「允许」，确认框退回终端。
收件箱与一键跳转
长按灯呼出圆环菜单，按「需要你 → 运行中 → 刚刚完成 → 空闲」列出所有会话。 每行都能允许 / 拒绝、跳转到对应的终端标签页、静音该组或点「跑完叫我」； 离开超过十分钟再回来，顶部会一句话说明这段时间发生了什么。
一条上报，处处可见
一个 HTTP POST 进一处状态机，再分发到悬浮灯、收件箱、系统通知、 只读 Web 面板、手机推送、WLED 物理灯和多机汇总。它们走同一条路， 所以统计、历史、转发全都自动认，没有第二套状态机。

In action

它跑起来是什么样

还没装也能先看一眼：设置 →「演示」有五段循环场景，渲染的是真实的灯牌组件， 只是喂进去剧本数据 —— 不碰真实状态、不弹通知、不写历史。可以暂停、单步、重播。

Get started

开始用

四个平台的安装包由同一条流水线产出。安装包没有代码签名， 第一次打开会被系统拦一道；下面有 macOS 的处理办法。

下载安装包

macOS 的 .dmg（Apple Silicon 选 aarch64、Intel 选 x64）、Windows 的 -setup.exe 或免安装 zip、Linux 的 .AppImage / .deb。

github.com/iFishin/SignalHub/releases/latest

一行接上智能体

signalhub 命令已经打包在应用里，不用另外装；装完记得重启智能体。

# 装 hook，一行接上
signalhub install hooks claude-code
# 或者自己报一条状态
signalhub working --session demo

macOS 首次打开被拦下

递归清掉整个包的隔离标记，连打包在里面的 signalhub 命令一起覆盖到。

xattr -dr com.apple.quarantine /Applications/SignalHub.app

从源码运行

需要 Node.js 与 Rust 稳定版；Windows 还要装 Visual Studio C++ 生成工具。

git clone https://github.com/iFishin/SignalHub.git
cd SignalHub
npm install
npm run tauri dev
